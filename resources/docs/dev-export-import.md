**Website > Developer > Back up or move your website** downloads one JSON file with:

- the look (theme, colours, tagline, footer, social links)
- site settings (menu names, announcement bar, cookie notice, WhatsApp, extra CSS)
- every page with its sections, addresses, menu settings and sub-menus

Secrets, keys, webhooks, news posts and pictures are **not** included.

## Importing

Choose the file and decide:

- **Replace pages that already use the same address**: off by default. When off, only pages with new addresses are added.
- **Also apply the look, colours and settings**: off by default.

Everything is cleaned the same way as in the page editor. Pictures from another school are left out, because a school can only use its own pictures. Imported pages keep their *visible* setting. The home page is never moved: only its content is replaced, and only when you tick the box.

Use it to keep a backup before a big change, copy a good site to a sister school, or hand a ready-made site to a new school.
